# Security Policy

UpdateMeNow is a defensive and educational cybersecurity reporting tool.

## Supported Scope

Please report security issues that affect the UpdateMeNow CLI, packaging, configuration handling, exports, or source collection behavior.

## Out of Scope

UpdateMeNow v1 does not support:

- Exploitation assistance.
- Phishing assistance.
- Malware assistance.
- Credential theft.
- Offensive automation.
- Web scraping.
- Browser automation.
- CAPTCHA bypassing.

## Source Safety

UpdateMeNow should use only free public RSS feeds and official public APIs. The project should respect source terms and rate limits.
